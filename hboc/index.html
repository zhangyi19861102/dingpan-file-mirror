使用说明
  1. 版本列表：仅列出钉盘中实际存在的安装包，按版本号倒序；更新日志取自《汉邦输出中心版本更新记录》E 列。
  2. 版本分类：以 F 列「追踪记录」为准，含「已测试 / 已经测试 / 稳定版本」→ 正式版，其余（待测试 / 禁用 / 空 / 说明）→ Beta 版。
  3. 三个下载入口：「钉盘下载」直接唤起已登录的钉钉客户端打开这个安装包（不用网页扫码登录，首次点击浏览器会弹一次「打开钉钉」确认；exe 不能预览，打开后在它右上角点下载图标保存）；「网页下载」在浏览器打开钉盘网页版（首次需扫码）；「海外通道」从 GitHub 下载同一版本；GitHub 上已有该版本的包就点亮，没有则显示灰按钮。
  4. 下载统计与搜索：「钉盘下载 N 次 · 海外下载 N 次」是钉钉钉盘与 GitHub 服务端记录的真实下载数，随发布同步刷新；入口链接固定不变，搜索支持版本号、文件名与日志关键词。
